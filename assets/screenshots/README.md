# Capturas pendientes

Esta carpeta reserva los huecos referenciados por el README. Las capturas deben tomarse en Windows x64 con datos de Memory Lab, sin claves, nombres de usuario, rutas privadas ni procesos de terceros visibles.

- `main-window.png`: ventana completa, proceso Memory Lab adjunto en lectura-escritura, paneles de escaneo, resultados, vigilancia y chat visibles.
- `scan-results.png`: `Int32`, `Valor exacto`, candidato de `health` y estadísticas posteriores al refinamiento a 73.
- `memory-lab.png`: laboratorio completo mostrando direcciones, `health=100`, botones y log.
- `agent-confirmation.png`: modo guiado con la tarjeta de confirmación de una escritura, antes de aceptarla.

Formato recomendado: PNG, escala de Windows al 100 %, tema oscuro, ancho mínimo de 1280 px. Sustituir cada hueco con el archivo del nombre exacto; no versionar capturas con información sensible.
